Correctness and recovery contract. Stable event ID, message ID, order ID, correlation ID, schema version, and per-order sequence connect every boundary. SQL remains authoritative. Outbox prevents accepted-event loss; Inbox/deduplication prevents duplicate state transitions. Clients reconnect with their last sequence and refresh a snapshot before resuming. Expand/contract migrations keep blue and green versions compatible, and runtime credentials move to Vault without changing application contracts.
