What to notice

In-place mutation changes the parent's array length, but its reference is unchanged, so the OnPush child is skipped. Immutable replacement supplies a new reference, which marks the child and renders the complete current collection. A signal write also refreshes the parent without manual ChangeDetectorRef calls.
